This project is an unofficial, local-only integration helper for
DeepSeek Harness (DSH). It is not affiliated with, endorsed by, or supported by
DeepSeek or any of its affiliates.

Nature of the code:

- It contains original integration code and short string anchors used to locate
  insertion points inside the locally installed DSH application at run time.
- It does NOT redistribute DSH binaries, source code, or user data.
- It does NOT include credentials, account data, or personal data.
- It modifies files that belong to a DSH installation on the user's own machine.
  That may break future DSH updates or conflict with the application's terms.
  Use at your own risk; keep your own backups.
